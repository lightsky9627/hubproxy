各容器运行时接入配置指南

方式 A：全局配置 Docker 镜像加速（推荐，拉取无需加前缀）
修改 /etc/docker/daemon.json，添加或更新 registry-mirrors 节点：
{
  "registry-mirrors": [
    "https://hub.bravexist.cn"
  ]
}
执行重载生效：sudo systemctl daemon-reload && sudo systemctl restart docker
方式 B：直接拉取与第三方仓库登录拉取 
# 1. Docker Hub 公共镜像免登录直接拉取 (月度匿名配额 50GB)
docker pull hub.bravexist.cn/library/nginx:alpine
docker pull hub.bravexist.cn/redis:latest

# 2. 第三方镜像仓库（必须先使用分配的用户密码登录，如 gemini）
docker login k8s.hub.bravexist.cn -u gemini -p gemini
docker pull k8s.hub.bravexist.cn/ingress-nginx/controller:v1.11.1

# 3. GitHub 仓库镜像拉取
docker login ghcr.hub.bravexist.cn -u gemini -p gemini
docker pull ghcr.hub.bravexist.cn/home-assistant/core:latest
Containerd 镜像加速配置 (/etc/containerd/config.toml) 
[plugins."io.containerd.grpc.v1.cri".registry.mirrors]
  [plugins."io.containerd.grpc.v1.cri".registry.mirrors."docker.io"]
    endpoint = ["https://hub.bravexist.cn"]
  [plugins."io.containerd.grpc.v1.cri".registry.mirrors."registry.k8s.io"]
    endpoint = ["https://k8s.hub.bravexist.cn"]
重载生效：sudo systemctl restart containerd
Kubernetes Pod YAML 镜像引用示例
apiVersion: apps/v1
kind: Deployment
metadata:
  name: nginx-controller
spec:
  template:
    spec:
      # 若拉取第三方私有源，需配置 imagePullSecrets
      imagePullSecrets:
        - name: k8s-hub-secret
      containers:
        - name: controller
          image: k8s.hub.bravexist.cn/ingress-nginx/controller:v1.11.1
crictl & nerdctl & ctr 终端拉取示例 
# crictl 拉取测试
crictl pull hub.bravexist.cn/library/alpine:latest
crictl pull --auth "gemini:gemini" k8s.hub.bravexist.cn/ingress-nginx/controller:v1.11.1

# nerdctl (Docker 完全兼容 CLI)
nerdctl login k8s.hub.bravexist.cn -u gemini -p gemini
nerdctl pull k8s.hub.bravexist.cn/ingress-nginx/controller:v1.11.1

# ctr (containerd 原生调试工具)
ctr image pull hub.bravexist.cn/library/nginx:latest
ctr image pull -u "gemini:gemini" k8s.hub.bravexist.cn/ingress-nginx/controller:v1.11.1
