客户端接入指南

HubProxy 支持标准 Docker 客户端免配或凭证认证：

1. 终端登录（若管理员启用了配额或私有访问）
docker login hub.bravexist.cn
输入管理员为您分配的用户名与密码即可。
2. 专属二级域名免前缀直拉
docker pull <username>.hub.bravexist.cn/nginx:latest
