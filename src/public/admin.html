专属泛域名支持 (*.hub.bravexist.cn)

每个用户可以拥有专属二级域名（如 qiankong.hub.bravexist.cn），拉取免输用户名。

🚀 泛域名工作方式：
将 DNS 泛解析 *.hub.bravexist.cn 解析到本服务器，并通过 Nginx 透传 Host 头：
• 当客户端访问 <username>.hub.bravexist.cn 时，系统自动识别出其对应的用户空间；
• 即使不需要在命令中加各种复杂前缀，也能精准计费与配额统计。
Nginx 泛解析配置示例：
server {
    listen 443 ssl http2;
    server_name hub.bravexist.cn *.hub.bravexist.cn;

    ssl_certificate /path/to/wildcard.crt;
    ssl_certificate_key /path/to/wildcard.key;

    client_max_body_size 0;
    chunked_transfer_encoding on;

    location / {
        proxy_pass http://127.0.0.1:5000;
        proxy_set_header Host $http_host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto https;
        proxy_buffering off;
        proxy_request_buffering off;
    }
}
