上游账号

保存目标镜像平台的读取凭据，自动代为认证上游，突破 Docker Hub 匿名限制或拉取私有镜像。

支持 Docker Hub、GHCR、Quay 等，停用仍占名额。密码与密钥保存后无法查看，可随时替换。
配置 Docker Hub 上游凭据后，本服务端将代表所有经认证用户换取官方高配额 Token，彻底杜绝 429 Rate Limit。

专属域名 & Nginx 配置

推荐在前面挂载 Nginx 反向代理配置 SSL 证书，并传递真实客户端 IP。

标准 Nginx 反向代理配置示例：
server {
    listen 443 ssl http2;
    server_name hub.example.com;

    ssl_certificate /path/to/fullchain.pem;
    ssl_certificate_key /path/to/privkey.pem;

    client_max_body_size 0;
    chunked_transfer_encoding on;

    location / {
        proxy_pass http://127.0.0.1:5000;
        proxy_set_header Host $http_host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto https;
        proxy_read_timeout 900s;
        proxy_buffering off;
        proxy_request_buffering off;
    }
}
